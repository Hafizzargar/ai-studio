Put .ttf or .otf fonts here (only fonts whose licence allows your use, for example SIL OFL fonts such as Noto).
Subtitles use the font NAME set in project settings (default Arial), found by libass in this folder or in the system fonts.
For Urdu use a font such as "Noto Naskh Arabic" and set subtitles.font to that name in project.json.
Title cards use the first font file found here, otherwise Segoe UI / Arial on Windows.
